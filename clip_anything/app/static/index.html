            Privacy and safety

            • Nothing leaves this computer by default: no account, no upload, no telemetry. The recording, clips, report.json and the .clipanything analysis cache stay on your disk.
            • The only network use is what you turn on: the one-time captions model download from Hugging Face (asks first), a local Ollama model on 127.0.0.1, or a cloud AI provider (OpenAI or Anthropic) that receives small frames and caption text only when you set your own key. Set up installs ffmpeg and friends only after you say yes to each command.
            • This window is served from 127.0.0.1 with a token that changes every launch. The desktop app is not signed yet, so macOS and Windows warn once; check the download against SHA256SUMS.txt on the release page.
            • Clip choices, captions, titles and hooks are automated and labelled; they can be wrong. You are responsible for the rights to what you process and post: game video policies, music in the stream, other people's voice or likeness.
            • Recent runs and window size live in a clip-anything folder in your user data (Forget all clears recent runs); the first-run hint is remembered in this page's local storage.
