## B. Desktop app ("Clip Anything" window) — same library, zero new runtime deps if possible
- `clip_anything/gui.py`: a small window (tkinter from the stdlib; drag-and-drop via `tkinterdnd2` only if it packages cleanly on both OSes, else a big "Choose recording or folder" button + "Choose output folder"), options: number of clips (default 10), captions on/off, facecam auto/off, vertical crop follow/center; a progress bar + stage label driven by `pipeline.run(on_event=...)` in a worker thread; a Cancel button (cancel event); on finish, the clip list with scores and an "Open clips folder" button (`os.startfile` / `open` / `xdg-open`); errors shown in plain language (ffmpeg missing → the bundled one is used, so this should never happen in the packaged app). Entry point `clip-anything-gui` in pyproject and `python -m clip_anything.gui`.
- Packaging: PyInstaller one-folder (faster start) bundles for Windows (.zip with `Clip Anything.exe`) and macOS (.app in a .dmg or .zip), built by `.github/workflows/release.yml` on tag `v*` (permissions: contents: write only for the upload job; pinned actions; windows-latest + macos-latest (arm64) + macos-13 (x86_64) if cheap).
