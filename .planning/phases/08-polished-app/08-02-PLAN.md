## Intuitive (first-run clarity)
1. **One obvious next action at every moment.** Home: the drop zone is the hero (bigger, animated dashed border on drag-over, the file/folder name appears in it once chosen with its length and size, and the primary button reads "Make 10 clips" and updates with the slider). Nothing else competes above the fold; settings sit below with a single line "Defaults are good. Change them if you want."
2. **Plain words everywhere**: "Length: Short / Normal / Long (15–45 s)" stays; rename "Crop follows the action" → "Follow the action"; "Stack the facecam" → "Show my webcam on top"; "With AI" → "Smarter picks and titles (AI)". Every control has a one-line helper that says what you get, not how it works.
3. **First run guidance**: a 3-step hint strip the first time (Drop → Make clips → Post), dismissed forever after the first finished run (localStorage; try/catch).
4. **Readiness is quiet**: the top-right status becomes a single "Ready" dot, or "Set up captions / AI" link only when something is missing; a Set up screen stays one click away.
5. **Empty and error states** written like a person: no file yet, unsupported file, a folder with no videos, ffmpeg problem, a cancelled run, zero moments cleared the bar ("Nothing stood out. Try a lower bar." with a one-click "Lower the bar and run again").
6. **Results**: the first card is marked "Best moment"; each card's reason line is the headline (e.g. "A loud burst and fast motion together"), the score is secondary; a sticky bottom bar with "Open folder" and "Post text copied" confirmations (aria-live); clip cards hover-play muted, click for sound, keyboard: arrows move, Enter plays, Space pause.

## Nice (motion and craft, all with reduced-motion fallbacks)
7. Staggered entrance of cards; the live action curve draws with a leading dot; the progress bar fills smoothly and the stage label cross-fades; a satisfying "done" moment (the bar sweeps to magenta, the title changes to "Your clips", cards slide up); drag-over lift on the drop zone; button press feedback. Springs via CSS transitions with eased curves; no library.
8. Typography and spacing pass: consistent rhythm (8 px grid), max line lengths, headline sizes per screen, tabular numerals for times/scores.
9. Dark mode following the system (paper → ink inversion with the magenta kept), tested for contrast.
10. Window chrome: app icon, title "Clip Anything", remembers window size and last output folder (local only).
