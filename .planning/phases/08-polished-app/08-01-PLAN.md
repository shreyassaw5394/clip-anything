## Architecture
- `clip_anything/app/server.py`: stdlib `ThreadingHTTPServer` on 127.0.0.1:<free port>, per-launch random token in the URL/`Authorization`; Host and Origin checks on every request; WebSocket not needed: Server-Sent Events for progress (`/events`), JSON API: `POST /jobs` (paths + options) → runs `pipeline.run()` in a worker thread with cancel; `GET /jobs/<id>` (report); `GET /clips/<id>/<file>` (range requests so `<video>` scrubs); `POST /open-folder`; `GET /setup` + `POST /setup/install` (the one-shot setup steps with consent per step); `GET /caps`. Follow the user's security-hardening "local servers" rules exactly (bind loopback, Host allowlist, Origin/Sec-Fetch-Site checks on writes, token). Never serve files outside the output folder.
- `clip_anything/app/static/`: index.html, app.css, app.js, fonts (Barlow Condensed + Barlow, self-hosted, OFL files beside them), icons as inline SVG, CSP-strict (no inline styles/scripts; `default-src 'self'`; `media-src 'self'`). Served with the CSP header by server.py.
- Window: `pywebview` as an OPTIONAL extra (`[app]`), used when importable (native window, drag-and-drop file paths via its API); otherwise open the default browser to the tokened URL. Entry points: `clip-anything app` and `clip-anything-gui` (keep the old name working). The PyInstaller spec bundles the static folder (and pywebview if it packages cleanly on both OSes: measure; if it adds > 60 MB or fails on Windows CI, ship browser mode and say so).

## The product (design per the user's product-site-design skill: Apple restraint, nothing vibe-coded; style = the site's Brutalism + Minimalism print look in app form: paper #f1efe9, ink #111318, magenta #c4105f, Barlow; radius 0; big type; one accent)
1. **Home / drop zone**: "Drop a recording or a folder of clips" (drag-and-drop + Choose buttons), recent sessions list (from a small JSON in the user data dir; paths only), a quiet status line showing what's ready: ffmpeg ✓, captions ✓, AI model ✓/→ Set up.
2. **Settings strip** (defaults visible, nothing hidden behind menus): how many clips (slider 1–20), length (short / normal / long = 15–30 / 15–45 / 30–60), captions on/off, facecam auto/off, crop follow/centre, "With AI" toggle (shows what it does and, if a cloud key is set, that frames and text leave the machine).
3. **Run screen**: a single big progress bar with the stage names and a real time estimate; the action-score curve draws live as analysis streams (SSE) with markers popping where moments are found (the site's hero, live); Cancel.
4. **Results**: a grid of vertical clip cards with the real video (scrub by hover/drag, muted autoplay on hover, sound on click), rank, time in the recording, score, why-picked line, title/hook when AI ran; actions per card: Open, Reveal in folder, Copy post text, Delete; whole-run actions: Open folder, "Re-run with different settings" (uses the cache: seconds), Export report.
5. **Setup screen**: the `setup` steps as a checklist with one-click install buttons, each explained in one plain sentence and asking before installing; links to the exact manual steps.
6. **Feedback**: a "Tell us" link to the Tried-it issue and Discord; no telemetry.
Accessibility: keyboard for everything, focus visible, reduced motion, 4.5:1 contrast, labels; works at 1024x640 minimum and resizes down to a narrow window.
