- video_signals.py: build the proxy once (ffmpeg scale=320:-2, fps=5, rawvideo gray via pipe → numpy; never write a proxy file unless --keep-proxy); per 0.5 s window: motion intensity (mean abs frame diff, plus a cheap flow magnitude if opencv is fast enough), scene cut score (histogram delta / PySceneDetect-style threshold), flash score. - Action-following crop: per clip, compute the centre of motion mass per proxy frame (weighted centroid of |diff|), smooth with a strong low-pass (no jitter: max pan speed limit, dead-zone), map to source coords, output an ffmpeg crop expression over time (sendcmd/zoompan or piecewise crop via `crop=w:h:x(t):y(t)` with an expr built from keyframes). Fall back to centre crop if motion is diffuse.
- Tests: synthetic motion bursts are found; a synthetic moving square is followed (crop centre within tolerance); no pan faster than limit.
- Timing: 1-hour 1080p file analysed in < 5 min on the M1 (measure with a generated 10-min file and extrapolate; report).
