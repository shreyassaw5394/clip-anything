## A. `clip-anything setup` (and `--setup` on first run when something is missing)
- Checks, in order, printing one line each with ✓/→: ffmpeg+ffprobe (≥ 5; install via brew / winget `Gyan.FFmpeg` / apt / dnf / pacman when missing; on macOS prefer `ffmpeg-full` if captions are wanted), Python version, the `[captions]` extra (offer to install faster-whisper into the tool's own environment: with uv tools use `uv tool install --with` / `uvx --with`; detect how we were installed and print the exact command if we can't do it in-process), the Whisper model (download with consent), Ollama (detect `ollama` binary / 127.0.0.1:11434; offer `brew install ollama` / winget / the Linux script; then `ollama pull <small vision model>` with consent and size shown). `--yes` accepts all; `--no-ai` skips the Ollama part. Never installs anything silently; prints what it will do first, then does it, then re-checks. Idempotent: a second run is all ✓ and exits 0 in < 1 s.
- `scripts/install.sh` and `scripts/install.ps1` (create if absent on all branches, else leave a TODO note for the merge): detect-and-skip for uv, ffmpeg; then `uv tool install clip-anything` (or `--from git+...` until PyPI), then `clip-anything setup --yes`.

## B. `--ai` advanced mode (library-first: `clip_anything/ai.py`, provider abstraction)
- Providers: `ollama` (default when reachable; text model for titles/hooks e.g. the user's installed `llama3.2`/`qwen3`/`gemma3`, vision model for frames; auto-pick from `ollama list`), `openai`, `anthropic` (keys from env `OPENAI_API_KEY`/`ANTHROPIC_API_KEY` or `--ai-key`; never stored, never logged; clear one-line notice that frames/transcript lines go to that provider), `none`. `--ai-provider`, `--ai-model`, `--ai-vision-model`. Use stdlib urllib for all three (OpenAI chat completions with image_url data URLs; Anthropic messages API with image blocks, `anthropic-version` header); timeouts, size caps, graceful degrade to action-only with one warning, exactly like vision.py today (refactor vision.py into ai.py's Ollama provider rather than duplicating).
- What AI does in `--ai` (and nothing else): re-rank the top 3N candidates (blend 0.7 action / 0.3 AI), a 4–6 word title per clip, a one-line hook for the caption/post text (written to report.json and a `clips/<name>.txt` sidecar), and when captions exist pick the single best spoken line to feature as a big "reaction" caption. Prompts live in one file (`ai_prompts.py`) so the hosted service reuses them. Mark all AI text in the report as `ai_generated: true` and show the AI-disclosure line once.
