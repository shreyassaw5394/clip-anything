# 01-01 — Core: probe + audio signals → scoring/peaks → plain render → CLI end to end (steps 1–4 of GRAPH)

Deliver a working `clip-anything video.mp4` that outputs N vertical clips + report.json from audio signals alone.
- pyproject (hatchling, py>=3.11, scripts entry), ruff + pytest config, `uv sync`.
- scripts/make_test_video.py: ffmpeg testsrc2 1280x720 30fps 3 min + sine/noise base audio with 6 loud bursts at known times (gunfire-like noise bursts, 0.4–1.5 s) and 4 visual motion bursts (fast moving overlay/flashes) at known times; writes tests/fixtures/synth.mp4 (gitignored, regenerated by tests) + synth.json with the ground-truth times.
- probe.py: ffprobe JSON (duration, fps, size, codecs, audio present); extract 16 kHz mono wav to a temp dir (streamed, pipe if possible).
- audio_signals.py: windows of 0.5 s with 50% hop: RMS, spectral flux onset strength, loudness vs rolling 30 s median baseline; each normalised 0..1 (robust percentiles). Pure numpy/scipy.
- scoring.py: Signals → action score (weights from config), smoothing, peak picking (scipy.find_peaks with prominence + min distance), window expansion (60/40), snap to local quiet minima, overlap dedupe, clamp [min,max]. Unit tests with synthetic curves.
- render.py: ffmpeg one pass per clip: -ss/-to accurate seek, crop to 9:16 centre, scale 1080x1920, fade in/out 0.3 s, libx264 veryfast crf 20, aac 128k, faststart. Parallel renders (2–3 at once).
- report.py: report.json (rank, score, per-signal breakdown, start/end, title placeholder, path).
- cli.py: typer/argparse with the GRAPH contract, rich progress, ffmpeg check (exit 3 + install help), --dry-run.
- Tests: scoring unit tests; end-to-end on the synthetic video asserts every injected audio burst lands inside one of the top-6 clips.
Commit after each working step. Report: commands run, test output, timing on the synthetic video, what's weak.
