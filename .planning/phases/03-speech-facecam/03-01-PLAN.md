# 03-01 — Captions + excitement bonus + facecam (steps 7–8)
- speech.py: faster-whisper (lazy import; if not installed or model download fails → captions off with one clear line). Transcribe only the chosen clips' audio ranges (not the whole file) with word timestamps. Excitement bonus: shouts (RMS spike + speech), laughter, exclamation words list in config ("no way", "let's go", "oh my god", "what", "bro") → small score bonus only in the candidate stage (optional: --speech-rank to transcribe the whole file; off by default for speed).
- captions.py: word-synced ASS (bold, white with black outline, bottom-third safe zone for 9:16, 2–4 words per line, current word highlighted), burned with ffmpeg subtitles filter. Only when speech is detected in the clip. --no-captions skips everything.
- facecam.py: detect a static rectangular region in a corner of the proxy (low temporal variance border region) that contains a face (opencv haar cascade on a few frames); if found and --facecam auto: output layout = facecam on top (~30% height) + gameplay below (action-following crop), both 1080 wide. Tests with a synthetic facecam (static box with a face-like pattern is hard: use opencv's sample face image or a generated one; at least test the static-region detector).
